Requirements

Each task includes:

A class with a constructor and at least two methods.
A class docstring.
A demonstration using 2–3 independent objects.
At least three tests, including normal cases, edge cases, and invalid input.
Testing

Tests are written using the standard testing tools for the selected programming language.
