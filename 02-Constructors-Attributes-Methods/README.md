Requirements
Each task includes:
A class with a constructor and default values where appropriate.
Class attributes, class methods, and static methods where required.
Docstrings for the class and its methods.
A demonstration using 2–3 independent objects (except MathUtils, which does not require object creation).
At least three tests covering normal cases, edge cases, and invalid input.
Testing
Tests are written using the standard testing tools for the selected programming language.
For C++, tests can be implemented using assert from the <cassert> library, GoogleTest, or Catch2.
